## 搬瓦工 DC5 是什么机房？

DC5，也就是 USCA_5，是搬瓦工在洛杉矶提供的 E-Commerce SLA 专属机房。它并不是普通套餐里可以随意切换的通用机房，而是和 E-Commerce SLA 产品线绑定。

官方列出的主要网络方向包括：

- 中国电信 CN2 GIA / CTGNet，AS4809 / AS23764
- 中国联通 Premium，AS10099
- 中国移动 CMIN2，AS58807
- 多条 100Gbps 上行链路
- 自动故障切换
- 与 Apple、Google、Facebook、字节跳动等网络的直接互联
- 双网卡和双独立光纤路径
- 每台物理节点使用双路电力，并配备 UPS 和柴油发电机备份

这些配置解释了 DC5 的价格为什么明显高于搬瓦工的基础套餐。它卖的不是“便宜大碗”，而是更偏向业务连续性和网络稳定性的方案。

需要注意，CN2 GIA、联通 Premium 和 CMIN2 只是网络设计与上游线路描述，并不意味着所有地区、所有运营商、所有时间段都能获得完全相同的速度。实际访问效果仍会受到本地运营商、晚高峰拥塞、目标网站线路和 IP 质量影响。

## DC5 线路和延迟表现怎么样？

从线路定位看，DC5 主要解决的是美国服务器面向中国大陆访问时的跨境网络问题。

普通美国 VPS 可能会经过较复杂的国际中转，白天速度尚可，晚高峰却容易出现延迟上升、丢包或连接不稳定。DC5 通过电信 CN2 GIA、联通 Premium 和移动 CMIN2 分别优化三网访问路径，理论上比普通国际线路更适合中国大陆访客较多的网站。

第三方测评中，有报告对 DC5 进行了全国节点延迟和丢包测试，给出的平均响应时间约为 158.7 毫秒。不过，这类数据属于特定时间、特定实例和特定测试节点下的结果，不能直接当成所有用户的固定体验。

更实际的判断方式是：

- 你的主要访客是电信、联通还是移动用户？
- 访客集中在华东、华南、华北还是全国？
- 网站是否需要晚高峰持续稳定访问？
- 业务是静态页面，还是需要频繁读写数据库？
- 是否有备用节点或 CDN？

如果网站主要面向中国大陆用户，建议购买后分别在白天和晚高峰测试：

- `ping`
- `mtr`
- `traceroute`
- `curl`
- 下载和上传速度
- 网站首页与数据库接口响应时间

不要只看一次测速截图。VPS 测评最容易出现的问题，就是把某个时间点的漂亮数据写成永久承诺。

## 硬件性能：独享 AMD CPU 是重点

DC5 E-Commerce SLA 套餐使用 AMD dedicated CPU，官方配置从 2 核一直扩展到 12 核。内存从 1 GB 到 64 GB，硬盘从 20 GB 到 1280 GB，月流量最高达到 20 TB。

它和普通低价 VPS 的差别，主要不在于“有没有 SSD”，而在于资源分配方式：

- 20G、40G、80G 套餐分别提供独享 2 核、3 核和 4 核 AMD CPU
- 160G 到 1280G 套餐继续增加独享 CPU 数量
- 内存使用 ECC 配置
- 存储采用本地 RAID-10 SSD 或 NVMe RAID-10
- 端口从 2.5Gbps 提升到 5Gbps 或 10Gbps
- 所有 DC5 SLA 套餐都提供自动备份、快照和完整 root 权限

这类资源更适合运行 WordPress、WooCommerce、Laravel、Node.js、数据库服务、API、SaaS 后端或多个中小型网站。

但也别把“独享 CPU”理解成托管服务器。搬瓦工的 VPS 是 **self-managed**，也就是用户自己负责系统更新、安全配置、网站部署、数据库维护和故障排查。官方提供 KiwiVM 控制面板，用于开关机、重装系统、快照、备份、rDNS 和部分网络管理，但不会替你维护应用。

### 哪个套餐更值得选？

如果是个人网站、企业官网或访问量还没有明显增长的 WordPress 站点，20G 或 40G 已经够用。它们的主要限制不是 CPU，而是只有 1 GB 或 2 GB 内存。安装面板、数据库、缓存和多个插件后，1 GB 内存可能会比较紧张。

80G 是比较容易理解的起点：

- 4 GB 内存
- 4 核独享 CPU
- 3 TB 月流量
- 2.5Gbps 端口
- 支持月付

如果你想部署多个网站、WooCommerce、Node.js 服务或带后台管理系统的项目，80G 比 20G 和 40G 更从容。$69.99 月付也是 DC5 方案中较容易接受的门槛。

160G 和 320G 更适合有实际业务流量的用户。160G 提供 8 GB 内存和 5 TB 流量，320G 则提升到 16 GB 内存和 8 TB 流量。数据库、缓存、队列服务和多个应用同时运行时，内存余量会比低配方案更重要。

640G 以上属于高配业务方案。除非你确实需要大量存储、10Gbps 端口或更高流量额度，否则没有必要为了“配置看起来很大”而购买。服务器配置不是游戏装备，闲置的内存和流量不会自动产生收益。

## 99.99% SLA 到底意味着什么？

DC5 的卖点之一是 99.99% SLA。按照一年 365 天计算，99.99% 可用性对应的理论不可用时间约为 52.56 分钟。

但 SLA 不等于网站绝对不会宕机，也不等于所有访问失败都能获得赔偿。SLA 通常针对服务商能够控制的基础设施范围，具体适用条件、故障认定、赔偿方式和申请流程应以服务协议为准。

DC5 的官方基础设施描述包括：

- 双冗余边缘路由器
- 双冗余核心交换机和机架交换机
- 多条 100Gbps 上行链路
- 自动故障切换
- 双路电力
- UPS 和柴油发电机
- 双网卡和双光纤路径
- 24/7 监控

这些设计主要降低硬件、供电和网络单点故障的影响。它们并不能替代用户自己的备份、监控和安全策略。比如系统配置错误、程序崩溃、数据库损坏、域名解析错误或被攻击，通常不是购买 SLA 就能自动解决的问题。

## 每两周免费换 IP，有没有实际价值？

DC5 每两周可以免费更换一次 IP，这是它区别于普通 VPS 的功能之一。官方页面同时列出一个独立 IPv4、路由式 `/64` IPv6 子网，以及控制面板内即时更新 rDNS 的能力。

这个功能可能对以下情况有帮助：

- 新 IP 的信誉比旧 IP 更重要
- 邮件服务需要处理 IP 信誉问题
- 某个 IP 被目标平台限制
- 网站业务需要定期更换出口地址
- 测试不同 IP 的访问表现

不过，免费换 IP 不等于可以无限规避平台规则，也不代表新 IP 一定干净。更换 IP 后，仍然需要重新检查：

- IP 是否被列入黑名单
- 邮件端口和反向解析是否正常
- 网站 CDN 或防火墙是否需要更新
- SSH、API 白名单是否需要同步
- DNS 是否仍然指向旧地址

如果你只是搭建个人博客，可能很少用到这个功能；如果你运营多个线上业务，它的价值会更明显。

这里的“业务”不一定要是大型电商。一个有稳定收入的中小网站，如果停机几十分钟会造成订单、线索或客户流失，也可能需要更高的可用性保障。

### 适合有 Linux 运维能力的用户

搬瓦工提供的是自管理 VPS。你需要自己处理：

- Linux 初始化

- 防火墙

- 系统升级
- 网站监控

如果你完全不想接触服务器命令行，DC5 可能不是合适的产品。它提供的是基础设施，不是托管建站服务。
